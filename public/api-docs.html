foodmap 美食探店地图 · API 文档

把店铺清单一键生成可导航的美食合集地图。本页为开发者/Agent 调用说明，机器可读版本见 /llms.txt。

核心端点：创建合集（一个请求完成）

POST http://8.134.63.180:3000/api/collections/generate
Authorization: Bearer <token>
Content-Type: application/json

{
  "title": "周末深圳火锅巡礼",
  "city": "深圳",
  "places": [
    { "name": "蜀大侠火锅" },
    { "name": "周记肠粉王" }
  ]
}

响应 201：{"mapId":"...","url":"http://8.134.63.180:3000/maps/...","added":2,"missing":[]} —— url 即合集页面链接；missing 列出搜不到的店。

第一步：获取凭证

接口说明
POST /api/auth/register注册：{email, password, nickname}
POST /api/auth/login登录：{email, password} → 返回 accessToken（15分钟）
POST /api/auth/refresh续期：{refreshToken} → 新 token

辅助接口

接口说明
GET /api/geo/search?keyword=店名&city=城市按店名搜索坐标（无需鉴权）
GET /api/maps?city=城市浏览公开合集
⚠️ 城市很重要：店名缺坐标时服务端用高德自动补全，必须提供 city（顶层或每家店），否则可能匹配到错误城市的同名店。

请求参数说明

字段必填说明
title是合集标题，≤60 字
city建议城市（如"深圳"），用于坐标补全
places[].name是店名
places[].city否单店城市，覆盖顶层 city
places[].lng/lat否已有坐标可直传，跳过搜索
places[].address/category/phone否可选补充信息
